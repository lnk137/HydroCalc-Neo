# 指标定义与迁移说明

这里描述软件实际实现，不代表已经通过特定论文、实验室标准或人工标注的科学准确性认证。

## 输入与标定

掩码内部 `255` 代表染色，导出时黑色 `0` 代表染色。所有指标使用同一张无标线二值掩码。二值输入用灰度 ≤127 判为染色；HSV 输入以所选范围为染色。

设图像宽高为 W、H 像素，真实剖面宽高为 L、D cm，染色像素数为 N，每行染色比例为 r(y)。

- 单像素面积：`L × D / (W × H)` cm²。
- 单行高度：`D / H` cm。
- 起始深度使用 cm，换算为起始行后寻找基质流边界。

## 定义

| 指标 | 实现 |
| --- | --- |
| 染色面积 | `N × L × D / (W × H)` |
| 染色面积比 | `100 × N / (W × H)` |
| 基质流深度 | 起始深度后首个 `r(y) ≤ matrix_threshold` 的行号乘单行高度；没有此行则为整个剖面高度 |
| 优先流百分数 | 基质流边界以下实际染色像素数 / 全部染色像素数 ×100 |
| 优先染色面积比 | 基质流边界以下实际染色像素数 / 全部像素数 ×100 |
| 最大染色深度 | `r(y) ≥ depth_threshold` 的最深一行下边界的物理深度 |
| 长度指数 | `100 × Σ abs(r(y) − r(y−1))` |

默认基质阈值 0.8、最大深度阈值 0.005。长度指数可以超过 100，不是百分比。全空白图七项指标均为零；全染色图的基质流深度和最大深度等于整个剖面高度，优先流百分数为零。

## 可配置计划湿润层（算法版本 2.4-planned-wetting）

在设置的“分析参数 → 剖面尺度”中输入计划湿润层深度 Zr，单位 cm，默认 40。允许输入正小数，范围为 0.01–10000 cm。真实剖面高度 D 由图片实际覆盖范围标定，例如计划湿润层为 60 cm、拍摄剖面为 80 cm 时，填写 Zr=60、D=80。

每行 DC 继续采用百分数 `100 × 染色像素数 / 行宽`，A_root、A_tot 的单位为 `%·层`。有效湿润层数为 `N_root = Zr × H / D`。边界行按实际深度覆盖比例 `clamp(Zr × H / D − y, 0, 1)` 计入湿润层。全部图像行参与 A_tot。

| 保存字段 | 当前定义 |
| --- | --- |
| `a_root` | 从表面到计划湿润层 Zr 的 DC 加权累加值 |
| `a_tot` | 从表面到实际剖面底部 D 的全部逐行 DC 累加值 |
| `root_layer_count` | `Zr × H / D`，允许为非整数 |
| `total_layer_count` | 实际处理行数 H |
| `rdpr_percent` | `100 × (1 − A_root / A_tot)`，计划湿润层以下染色占总染色的百分比 |
| `ea_percent` | `100 × A_root / A_tot`，计划湿润层内染色占总染色的百分比 |
| `es_percent` | `A_root / N_root`，计划湿润层内平均 DC 百分数 |

500 行、50 cm、Zr=40 cm 时，有效湿润层数为 400，与此前默认结果一致。80 cm 剖面、100 行、Zr=60 cm 时，有效湿润层数为 75，最后 25 行属于计划湿润层以下区域。50 cm 以下的已拍摄土层也参与全剖面总量。

湿润层视图 `wetting.png` 用青绿色表示计划湿润层内染色，红色表示其下方的深层渗漏染色，白色表示背景，红色虚线标示边界。边界穿过像素行时按覆盖比例混合该行两种染色颜色。参考线图和二值掩膜仍分别生成，彩色标记只绘制到独立副本。深度曲线按同一物理边界分色并标注 Zr，全部数据行参与绘图。

Zr 超过已标定剖面高度时，设置页显示提示，A_root、湿润层有效层数和三项百分数为 null，全剖面总量与行数仍可计算。空白图在湿润层完整覆盖时 A_root、A_tot、Es 均为零，RDPR、Ea 因零分母为 null。Zr 等于剖面底部且存在染色时 RDPR=0%、Ea=100%。

设置文件缺少新参数时补入默认 40 cm。每次分析保存当时的参数、物理边界和 `total_scope=full_profile`。已有 2.3 历史仍使用原先保存的 40/50 cm 定义，详情页显示当时边界。重新分析使用当前设置产生新记录。单项和批量结果包包含湿润层图，指标 CSV 与批量汇总附计划湿润层深度及实际总深度，混合历史导出可追溯各自定义。

## 交互预览与图版

当前湿润层视图将二值掩膜和 DC 曲线放在同一条物理深度轴上。拖动红色边界、使用方向键或精确数值输入时，由掩膜原始逐行计数的前缀和即时计算当前深度的 A_root、RDPR、Ea、Es。部分行继续按深度覆盖比例计入，损失率响应曲线使用全部行边界。悬停时，灰线对齐剖面与曲线的同一层，并显示该层的中心深度和染色比例 DC。红色边界仍可调节，并可固定多个深度比较。

交互时先实时预览。松开红线或调节键、确认深度输入或点击固定对比点后，系统复用该记录的分割参数和原图自动分析，生成独立历史记录。计算时保留当前剖面和对比点。取消拖动会回到调整前深度，失败时恢复上次保存的深度。旧版记录也可通过修改深度生成当前版本结果。全局默认设置由设置页管理。

顶部导出菜单中的“剖面图版 (PNG)”生成 2000×1520 px PNG，包含剖面、DC 曲线、边界深度、三项指标、损失率响应曲线、固定对比标记和物理标定。该图版使用白色背景。深度调整完成后即可导出当前结果。批量导出始终读取对应的已保存历史。

图像、分析指标、曲线和分析信息各自位于可移动、可缩放的卡片中。分析指标卡集中显示根区和优先流数据，根区分组仅显示 RDPR、Ea、Es 三个指标和计划湿润层控件。百分比条以 100% 为满刻度，深度条以该记录的全剖面深度为满刻度。累加量与层数仍可从导出结果读取。恢复旧布局时系统会合并两张指标卡并收紧间距。拖动时卡片自动补位，松手时吸附并保存排列。红线、数值预览与固定对比在模式切换时保留。图像、DC 曲线和深度刻度在卡片放缩时共同适配。卡片排列只影响显示，不修改物理标定或像素计数。

## 固定边界根区指标（历史算法版本 2.3-root-zone）

固定边界算法采用百分数 DC。每行 `DC(y) = 100 × n(y) / W`，其中 `n(y)` 为该行实际染色像素数。A_root、A_tot 均按这个尺度累加，单位为 `%·层`，同一分子分母的尺度一致。

令单行高度 `h = D / H`，根区有效层数 `N_root = 40 / h`，全剖面有效层数 `N_tot = 50 / h`。行号从 0 开始，某行对边界深度 Z 的权重为 `w(y,Z) = clamp(Z / h − y, 0, 1)`。

| 保存字段 | 定义及单位 |
| --- | --- |
| `a_root` | `Σ DC(y) × w(y,40)`，0–40 cm 的 DC 百分数累加值，%·层 |
| `a_tot` | `Σ DC(y) × w(y,50)`，0–50 cm 的 DC 百分数累加值，%·层 |
| `root_layer_count` | `40 / h`，允许为非整数 |
| `total_layer_count` | `50 / h`，允许为非整数 |
| `rdpr_percent` | `100 × (1 − A_root / A_tot)`，根区深层渗漏损失率，% |
| `ea_percent` | `100 × A_root / A_tot`，灌水效率，% |
| `es_percent` | `A_root / N_root`，有效储水率，% |

500 行、50 cm 时，单行高度为 0.1 cm。根区为前 400 行（索引 0–399），全剖面为全部 500 行（索引 0–499）。若合成掩膜的根区黑格数为 33050、全剖面黑格数为 33150，每行 500 格，对应 `A_root = 33050 / 500 × 100 = 6610`、`A_tot = 6630`、`Es = 16.525%`。RDPR、Ea 的无量纲公式分别为 `1 − A_root / A_tot` 和 `A_root / A_tot`，界面和保存字段乘 100 后使用百分数。

分辨率改变时，Es 的分母随根区有效层数改变。边界落在行内时，把该行视为 DC 均匀的薄层，按深度覆盖比例加权。例如 64 行、60 cm 时，40 cm 对应 42 又 2/3 层，50 cm 对应 53 又 1/3 层。50 cm 以下的染色不计入这组新指标。宽度变化由每行染色像素数除以实际处理宽度处理。

原始计数直接来自既有分析掩膜，先以 long double 累加未舍入的加权像素数，再除以行宽并乘 100，得到与逐层 DC 累加相等的中间量。A_root、A_tot 和三个比例在 JSON 与指标 CSV 中保留双精度，界面显示精度分别为最多 6 位和 4 位小数。原有深度图的舍入显示不参与新指标计算。`profile.csv` 前两列保持深度和 DC 百分数，后续附原始 `stained_pixels`、`row_width`、`root_weight`、`total_weight`、`root_dc_contribution`、`total_dc_contribution`。最后两列的累加可复核 A_root、A_tot，浮点求和末位可能存在机器精度差异。

### 可用性与历史记录

- 剖面高度至少 50 cm 时可计算全部新指标。`A_tot = 0` 时 RDPR、Ea 为 `null`，Es 为 0，状态为 `zero_staining`，界面显示破折号并解释零分母。
- 剖面高度处于 40–50 cm 时保留 A_root、根区有效层数、Es。A_tot、全剖面有效层数、RDPR、Ea 为 `null`。
- 剖面高度小于 40 cm 时，新指标和有效层数均为 `null`。深度不足的状态为 `insufficient_depth`，软件不会补齐未拍摄的土层。
- 旧历史记录保持原始计算结果，打开详情时缺项显示破折号。调整计划湿润层深度会生成独立的新结果。批量汇总状态为 `not_computed`，相应新列留空。新记录保存 `root_zone` 定义、单位、边界处理方式和版本号，并进入 SQLite 历史、单项 CSV、单项结果包和批量结果包。

这些指标由染色分布计算，科学解释尚缺独立实验标定。

## 相对旧代码的修正

旧版固定按 10 px/cm 计算，且优先面积使用 `染色面积 − 宽度 × 基质深度`，这会在宽度、分辨率变化或基质区未完全染色时产生不一致甚至负数。新版按真实宽高标定，并直接数基质边界以下的染色像素。因此新版结果不保证逐值复现旧版。

旧版最大深度使用稀疏行累计及整数取整，可能把不相邻的两行作为停止条件。新版使用明确阈值的最深有效行。

调整分辨率仍可能改变边界附近的分割像素；尺度不变测试针对相同形状的理想掩码，不能保证任意照片在不同重采样尺寸下数值完全相同。

自动识别仅在 ≥98% 像素满足 RGB 通道差≤2 且接近黑（≤20）或白（≥235）时选择二值模式，其他图片选择 HSV，避免单凭暗色比例判断。

K-means 在 HSV 空间使用固定随机种子、最多 20000 个拟合样本。降噪前后的两种变体分别归类并统计。颜色面积包含白色背景，不应将每类面积都理解为染色面积。


## 可切换降噪（算法版本 2.2-denoising）

HSV 分割按调整分辨率、所选降噪、转 HSV、范围分割的顺序执行。设置中的 denoise_enabled 控制总开关，denoise_method 可选 bilateral、median、nlm。切换算法保留各自参数，所有参数随分析快照保存。二值输入直接阈值化。

| 算法 | 参数 | 默认值 | 可调范围 |
| --- | --- | --- | --- |
| 双边滤波 | 邻域直径 bilateral_diameter | 5 px | 1–31 的奇数 |
| 双边滤波 | 颜色尺度 bilateral_sigma_color | 25 | 0.1–255 |
| 双边滤波 | 空间尺度 bilateral_sigma_space | 5 px | 0.1–255 |
| 中值滤波 | 窗口 median_kernel | 3 px | 3–31 的奇数 |
| 彩色非局部均值 | 亮度强度 nlm_h | 5 | 0–50 |
| 彩色非局部均值 | 颜色强度 nlm_h_color | 5 | 0–50 |
| 彩色非局部均值 | 图块窗口 nlm_template_window | 7 px | 3–31 的奇数 |
| 彩色非局部均值 | 搜索窗口 nlm_search_window | 21 px | 3–99 的奇数，且不小于图块窗口 |

双边滤波在 BGR 空间执行，使用 OpenCV 默认边界外推。中值滤波使用 OpenCV medianBlur。彩色非局部均值使用 OpenCV photo 模块的 fastNlMeansDenoisingColored，亮度与颜色分量分别处理。上述方法都可能改变阈值附近的分类，降噪无法单独判定小斑块的物理意义。

旧设置中的 blur_kernel 迁移为开关和双边邻域直径，0 对应关闭，3、5、7 对应保留邻域值。显式的新字段优先。旧版本 2.1-bilateral 的 sigmaColor 为 25，sigmaSpace 为 5。已有分析仍按原始参数快照显示。

preprocessing 记录真正参与分割的算法与所用参数，关闭降噪或二值输入记录 method=none。七指标、二值图和矩阵使用同一掩膜。聚类变体复用已降噪颜色图，再将掩膜外背景设为白色。文件名及统计键 clusters_blurred 保持历史接口兼容，由设置快照确定其实际算法。
